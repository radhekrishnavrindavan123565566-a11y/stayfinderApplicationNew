GOOGLE ADSENSE INTEGRATION GUIDE
================================

SETUP STATUS: READY TO CONFIGURE
Current File: Publisher ID shown in AdSense dashboard

STEP 1: GET YOUR ADSENSE PUBLISHER ID
=====================================

1. Go to: https://www.google.com/adsense/
2. Sign in with your Google account
3. Navigate to Settings → Account
4. Copy your Publisher ID (format: ca-pub-xxxxxxxxxxxxxxxx)
5. Add to .env file: NEXT_PUBLIC_ADSENSE_PUBLISHER_ID=ca-pub-xxxxxxxxxxxxxxxx

STEP 2: CREATE AD SLOTS IN ADSENSE DASHBOARD
=============================================

For each location where you want ads, create a slot:

1. Go to Ads → By code in AdSense dashboard
2. Click "Create new ad unit"
3. Fill in details:
   - Name: Descriptive name (e.g., "Homepage Banner", "Property Sidebar")
   - Type: Display ads (for responsive/flexible ads)
   - Size: Choose appropriate size or responsive
4. Copy the ad slot ID (format: 1234567890)
5. Add to .env file

RECOMMENDED AD PLACEMENTS:
==========================

1. HOMEPAGE BANNER (728x90 or responsive)
   - Placement: Top of hero section or between property cards
   - Slot ID: NEXT_PUBLIC_ADSENSE_SLOT_HOME_HORIZONTAL

2. PROPERTY LISTING SIDEBAR (300x600)
   - Placement: Right sidebar on property search/listing page
   - Slot ID: NEXT_PUBLIC_ADSENSE_SLOT_PROPERTY_SIDEBAR

3. PROPERTY DETAIL PAGE (Multiple locations)
   - Top: Above property description
   - Slot ID: NEXT_PUBLIC_ADSENSE_SLOT_PROPERTY_DETAIL_TOP
   - Bottom: Below reviews section
   - Slot ID: NEXT_PUBLIC_ADSENSE_SLOT_PROPERTY_DETAIL_BOTTOM

4. DASHBOARD SIDEBAR (300x600)
   - Placement: Right sidebar on dashboard
   - Slot ID: NEXT_PUBLIC_ADSENSE_SLOT_DASHBOARD_SIDEBAR

5. SEARCH RESULTS (728x90)
   - Placement: Between search filters and results
   - Slot ID: NEXT_PUBLIC_ADSENSE_SLOT_SEARCH_RESULTS

6. IN-ARTICLE ADS (Responsive)
   - Placement: Within blog posts or detailed content
   - Slot ID: NEXT_PUBLIC_ADSENSE_SLOT_IN_ARTICLE

USAGE IN COMPONENTS
===================

Import and use the AdSenseAd component:

```
import AdSenseAd from '@/components/ads/AdSenseAd';
import { AD_SLOTS } from '@/lib/adsense';

// In your component
<AdSenseAd
  slotId={AD_SLOTS.homeHorizontal.slotId}
  slotName="homeHorizontal"
  format="auto"
  responsive={true}
/>
```

ADSENSE POLICIES & BEST PRACTICES
==================================

DO:
✓ Place ads in visible locations
✓ Mix ad formats for better user experience
✓ Use responsive ads for mobile
✓ Monitor ad performance in AdSense dashboard
✓ Maintain good user experience (don't overload with ads)
✓ Comply with AdSense publisher policies
✓ Test with real ads before going live

DON'T:
✗ Click on your own ads (violates policy)
✗ Place too many ads on one page (max 3 per page recommended)
✗ Hide ads or make them deceptive
✗ Use misleading content around ads
✗ Traffic from bots or artificial means
✗ AdSense on pages with adult content
✗ Violate publisher code of conduct

APPROVAL PROCESS
================

1. Add AdSense code to your website
2. Submit site for review in AdSense dashboard
3. Google reviews your site (24-48 hours typically)
4. Once approved, ads will start showing
5. Earnings appear in AdSense account

MONITORING & ANALYTICS
======================

1. AdSense Dashboard:

TROUBLESHOOTING
===============

Issue: Ads not showing
Solution:
- Verify Publisher ID in .env
- Check slot IDs are correct
- Ensure website is approved
- Wait 24-48 hours after first setup
- Check AdSense dashboard for errors

Issue: Low earnings
Solution:
- Improve content quality
- Increase traffic to site
- Optimize ad placements
- Test different ad formats
- Check AdSense policies compliance

Issue: Ads blocked by adblockers
Solution:
- Inform users about benefits of ads
- Consider AdSense payment option
- Implement ads.txt file
- Use proper ad labeling

Issue: Invalid traffic warning
Solution:
- Stop clicking own ads
- Monitor referral traffic
- Check bot/crawler settings
- Use proper analytics
- Review AdSense policies

REVENUE ESTIMATION
==================

Factors affecting earnings:
- Traffic volume (more traffic = more revenue)
- Content quality (better content = higher CPM)
- Geographic location (US/UK traffic worth more)
- Ad placement (visible ads get more clicks)
- User engagement (engaged users click ads)

Typical CPM ranges:
- US/UK/Canada/Australia: $5-$15 CPM
- Europe: $3-$8 CPM
- India/Southeast Asia: $0.50-$2 CPM
- Global average: $2-$5 CPM

Example calculation:
- 10,000 visitors/month
- 40% ad view rate
- 4,000 impressions
- $5 average CPM
- Monthly earnings: $20
