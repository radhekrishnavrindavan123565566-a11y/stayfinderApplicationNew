GOOGLE ADS TESTING GUIDE - HOW TO CHECK ADS ON YOUR WEBSITE
============================================================

PART 1: SETUP PREREQUISITES
===========================

Before you can see Google Ads on your website, you need:

1. Google AdSense Account Created
   ✓ Go to: https://www.google.com/adsense/
   ✓ Sign in and accept the Publisher Agreement
   ✓ Get your Publisher ID (format: ca-pub-xxxxxxxxxxxxxxxx)

2. Ad Slots Created in AdSense Dashboard
   ✓ AdSense Dashboard → Ads → By code → Create new ad unit
   ✓ Create 7 ad slots (or as many as you need)
   ✓ Copy each slot ID (numeric value like 1234567890)

3. Environment Variables Added to .env
   ✓ Add Publisher ID: NEXT_PUBLIC_ADSENSE_PUBLISHER_ID=ca-pub-xxxxx
   ✓ Add all slot IDs: NEXT_PUBLIC_ADSENSE_SLOT_HOME_HORIZONTAL=1234567890
   ✓ Reload your dev server after changing .env

4. AdSenseAd Component Added to Pages
   ✓ See PART 3 for implementation examples


PART 2: TESTING GOOGLE ADS LOCALLY (Development)
=================================================

METHOD 1: Using Browser Developer Tools (Fastest)
--------------------------------------------------

Step 1: Add test Publisher ID temporarily
   - In your .env file, set a valid Publisher ID
   - Example: NEXT_PUBLIC_ADSENSE_PUBLISHER_ID=ca-pub-xxxxxxxxxxxxxxxx
   - Save and restart dev server: npm run dev

Step 2: Navigate to a page with AdSenseAd component
   - Open your website at http://localhost:3000
   - Go to a page where you added the <AdSenseAd /> component

Step 3: Open Browser DevTools (F12)
   1. Press F12 or Right-click → Inspect
   2. Go to Console tab
   3. Look for logs like: "[AdSense] Ad impression: homeHorizontal (1234567890)"
   4. This confirms the ad component is trying to load

Step 4: Check Network Tab for AdSense Script
   1. Go to Network tab in DevTools
   2. Look for requests to: pagead2.googlesyndication.com
   3. You should see:
      - GET request to pagead/js/adsbygoogle.js
      - Status: 200 (if loaded successfully)
      - Size: ~50KB-100KB

Step 5: Inspect the Ad Element
   1. Go to Inspector/Elements tab
   2. Look for <ins class="adsbygoogle"> elements
   3. Check these attributes:
      - data-ad-client="ca-pub-xxxxx" (should match your Publisher ID)
      - data-ad-slot="1234567890" (should match your slot ID)
      - data-ad-format="auto" or "vertical" etc.

If you see these elements, ads are trying to load!


METHOD 2: View Console Logs
---------------------------

Step 1: Open Developer Tools (F12)
Step 2: Go to Console tab
Step 3: Filter by searching "AdSense"

You should see logs like:
   [AdSense] Ad impression: homeHorizontal (1234567890)
   [AdSense] Ad impression: dashboardSidebar (1234567894)

This means:
✓ Ad component rendered
✓ Publisher ID loaded
✓ Slot IDs are correct
✓ AdSense script is initializing


METHOD 3: Check .env is Loaded
-------------------------------

Step 1: In Browser Console, run:
   console.log(process.env.NEXT_PUBLIC_ADSENSE_PUBLISHER_ID)

Step 2: You should see:
   ca-pub-xxxxxxxxxxxxxxxx

If you see "undefined", then:
   - .env file not loaded
   - Need to restart dev server (npm run dev)
   - Check .env file has the correct format


PART 3: IMPLEMENTING ADSENSE ON PAGES
======================================

Step 1: Import Components
   import AdSenseAd from '@/components/ads/AdSenseAd';
   import { AD_SLOTS } from '@/lib/adsense';

Step 2: Add to Your Page

EXAMPLE 1: Add Ad to Homepage (app/page.tsx)
--------------------------------------------

'use client';

import AdSenseAd from '@/components/ads/AdSenseAd';
import { AD_SLOTS } from '@/lib/adsense';

export default function HomePage() {
  return (
    <main>
      {/* Hero Section */}
      <section className="hero">
        <h1>Welcome to Stayerra</h1>
        <p>Find your perfect stay</p>
      </section>

      {/* Google Ad - Horizontal Banner */}
      <div className="my-8 px-4">
        <AdSenseAd
          slotId={AD_SLOTS.homeHorizontal.slotId}
          slotName="homeHorizontal"
          format="auto"
          responsive={true}
        />
      </div>

      {/* Property Listings */}
      <section className="properties">
        {/* Your property grid here */}
      </section>
    </main>
  );
}

PART 4: TESTING CHECKLIST
=========================

Before going live, verify:

□ Environment Variables Loaded
  - Check: console.log(process.env.NEXT_PUBLIC_ADSENSE_PUBLISHER_ID)
  - Should show: ca-pub-xxxxxxxxxxxxxxxx

□ Ad Component Renders
  - Look for: <ins class="adsbygoogle"> in Inspector
  - Should have: data-ad-client, data-ad-slot attributes

□ AdSense Script Loads
  - Network tab should show: pagead2.googlesyndication.com
  - Status should be: 200

□ Console Logs Present
  - Look for: "[AdSense] Ad impression:" messages
  - Should show: ad slot name and ID

□ Ad Placeholder Visible
  - If ads not showing, should see gray placeholder
  - Text: "[Ad Space - Enable Google AdSense]"

□ All Slot IDs Correct
  - Match .env slots with AdSenseAd components
  - Should not be empty strings


PART 5: WHAT YOU'LL SEE
======================

SCENARIO 1: Ads Are Loading Properly
------------------------------------
✓ Gray or white ad area appears
✓ AdSense banner shown with ads
✓ Console logs show ad impressions
✓ Network shows pagead2.googlesyndication.com loaded

SCENARIO 2: Ads Not Showing (Placeholder Visible)
-------------------------------------------------
This is normal initially! Reasons:
- Website not approved yet (24-48 hours)
- Slot IDs not created in AdSense
- Publisher ID incorrect
- Website not live yet
- AdSense account in review

Gray box with "[Ad Space - Enable Google AdSense]" means:
✓ Component is set up correctly
✓ Just waiting for approval

SCENARIO 3: No Placeholder, Just Empty Space
--------------------------------------------
Debug steps:
1. Check .env file has NEXT_PUBLIC_ADSENSE_PUBLISHER_ID
2. Restart dev server: npm run dev
3. Check Browser DevTools Console for errors
4. Verify slot IDs are not empty in .env


PART 6: PRODUCTION TESTING (After Deploy)
==========================================

Step 1: Deploy to Vercel
   - Push code to GitHub with AdSenseAd components
   - Vercel deploys automatically
   - Website goes live at: https://yourdomain.com

Step 2: Test on Production
   1. Visit https://yourdomain.com
   2. Open DevTools (F12)
   3. Check Console for "[AdSense] Ad impression:" logs
   4. Check Network for pagead2.googlesyndication.com

Step 3: Google Ads Review
   1. Google reviews your website
   2. Takes 24-48 hours typically
   3. Check AdSense dashboard for approval status

Step 4: Ads Start Showing
   1. Once approved, real ads appear
   2. Not placeholder ads
   3. Earnings show in AdSense dashboard
   4. Can take 24-48 hours to start serving ads


PART 7: TROUBLESHOOTING
=======================

Issue: Ads not showing, just gray placeholder
Solution:
   1. Check .env file - NEXT_PUBLIC_ADSENSE_PUBLISHER_ID must be set
   2. Restart dev server: npm run dev
   3. Clear browser cache: Ctrl+Shift+Del
   4. Check AdSense website approval status
   5. Wait 24-48 hours if website recently added

Issue: Console error "adsbygoogle is not defined"
Solution:
   1. Publisher ID might be wrong
   2. Check: NEXT_PUBLIC_ADSENSE_PUBLISHER_ID in .env
   3. Format should be: ca-pub-xxxxxxxxxxxxxxxx
   4. Restart dev server after changing .env

Issue: AdSenseAd component not rendering at all
Solution:
   1. Check import statement:
      import AdSenseAd from '@/components/ads/AdSenseAd';
   2. Check component is used:
      <AdSenseAd slotId={...} slotName={...} />
   3. Verify slot ID is not empty
   4. Check browser console for React errors

Issue: Seeing placeholder on some pages, ads on others
Solution:
   1. Normal if not all slots created yet
   2. Create missing slots in AdSense dashboard
   3. Add slot IDs to .env
   4. Restart dev server
   5. Pages with valid slots will show ads first

Issue: Ads show locally but not on production
Solution:
   1. Check .env variables copied to Vercel
   2. Set in Vercel Settings → Environment Variables:
      - NEXT_PUBLIC_ADSENSE_PUBLISHER_ID=ca-pub-xxxxx
      - NEXT_PUBLIC_ADSENSE_SLOT_HOME_HORIZONTAL=1234567890
      - (All other slots)
   3. Redeploy Vercel project
   4. Wait 24 hours for ads to be approved


PART 8: MONITORING ADS PERFORMANCE
===================================

AdSense Dashboard Reports:
1. Go to https://www.google.com/adsense/
2. Click "Reports" menu
3. View:
   - Earnings (by day, week, month)
   - Page views
   - Impressions
   - Clicks
   - RPM (Revenue Per Mille - $ per 1000 impressions)
   - CTR (Click-Through Rate)

Best Performing Ad Units:
1. Reports → Ad units
2. See which placements earn most
3. Optimize based on performance
4. Example: Dashboard sidebar might earn more than homepage

Tips to Increase Earnings:
- More traffic = more impressions
- Better content = higher CPM (Cost Per Mille)
- Optimize placements (above the fold)
- Use responsive ads
- Mix different ad formats
- High-quality content attracts premium ads
