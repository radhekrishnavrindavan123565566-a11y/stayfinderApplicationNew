================================================================================
POSTMAN/CURL TESTS - Copy these requests
================================================================================

1. REGISTER NEW USER
────────────────────

POST http://localhost:3000/api/auth/register
Content-Type: application/json

{
  "username": "testuser",
  "email": "test@example.com",
  "password": "Password123!",
  "role": "tenant"
}

Expected Response:
  Status: 201
  Body: { success: true, data: { user, accessToken, refreshToken } }


2. LOGIN USER
─────────────

POST http://localhost:3000/api/auth/login
Content-Type: application/json

{
  "email": "test@example.com",
  "password": "Password123!"
}

Expected Response:
  Status: 200
  Body: { success: true, data: { user, accessToken, refreshToken } }


3. CREATE BOOKING (Required for calendar & video tests)
──────────────────────────────────────────────────────

POST http://localhost:3000/api/bookings
Authorization: Bearer [your-access-token]
Content-Type: application/json

{
  "propertyId": "property-id",
  "startDate": "2024-08-15T10:00:00Z",
  "endDate": "2024-08-16T10:00:00Z",
  "message": "Test booking"
}

Expected Response:
  Status: 201
  Body: { success: true, data: { booking } }

Save the booking ID for calendar/video tests!


4. CREATE CALENDAR EVENT
─────────────────────────

POST http://localhost:3000/api/integrations/calendar/create
Authorization: Bearer [your-access-token]
Content-Type: application/json

{
  "bookingId": "[booking-id-from-previous-test]",
  "title": "Property Viewing",
  "description": "Test viewing for apartment",
  "attendees": ["owner@example.com", "tenant@example.com"],
  "includeLink": true
}

Expected Response:
  Status: 201
  Body: { 
    success: true, 
    calendarEvent: {
      eventId: "...",
      eventUrl: "...",
      calendarLink: "..."
    }
  }

Verify: Check Google Calendar for the event


5. CREATE VIDEO ROOM
──────────────────────

POST http://localhost:3000/api/integrations/videocall/create
Authorization: Bearer [your-access-token]
Content-Type: application/json

{
  "bookingId": "[booking-id-from-previous-test]",
  "duration": 60,
  "recordingEnabled": true,
  "maxParticipants": 10
}

Expected Response:
  Status: 201
  Body: {
    success: true,
    videoRoom: {
      roomId: "...",
      roomUrl: "https://...",
      provider: "daily",
      expiresAt: "..."
    }
  }

Verify: Click roomUrl to test video call


6. TRACK ANALYTICS EVENT
──────────────────────────

POST http://localhost:3000/api/integrations/analytics/track
Content-Type: application/json

{
  "eventName": "booking_created",
  "userId": "user-id",
  "properties": {
    "booking_id": "booking-123",
    "amount": 5000,
    "property_name": "Downtown Apartment"
  }
}

Expected Response:
  Status: 200
  Body: { success: true, message: "Event tracked successfully" }

Verify: Check Google Analytics dashboard after 30 seconds


7. REPORT ERROR
──────────────

POST http://localhost:3000/api/integrations/errors/report
Content-Type: application/json

{
  "errorName": "TestError",
  "errorMessage": "This is a test error for Sentry",
  "errorStack": "Error: Test\n    at Function",
  "userId": "user-123",
  "email": "test@example.com",
  "page": "/dashboard/bookings",
  "level": "error",
  "tags": {
    "component": "BookingForm",
    "action": "submit"
  }
}

Expected Response:
  Status: 201
  Body: { 
    success: true, 
    eventId: "...",
    message: "Error reported successfully"
  }

Verify: Check Sentry dashboard

ENVIRONMENT SETUP COMMANDS
================================================================================

Copy environment template:
  cp .env.example .env.local

View environment file:
  cat .env.local (Linux/Mac)
  type .env.local (Windows)

Edit environment file:
  nano .env.local (Linux/Mac)
  Open in VS Code (Windows)

Validate environment variables are set:
  npm run validate-env (if available)

Check specific variables:
  grep "GOOGLE_CALENDAR" .env.local
  grep "NEXT_PUBLIC_" .env.local


================================================================================
DATABASE COMMANDS
================================================================================

Connect to MongoDB with MongoDB Compass:
  Use MONGODB_URI from .env.local

List all collections:
  use stayerra
  show collections

Check bookings with calendar events:
  db.bookings.find({ calendarEventId: { $exists: true } })

Check bookings with video rooms:
  db.bookings.find({ videoRoom: { $exists: true } })

Clear test data:
  db.bookings.deleteMany({ email: "test@example.com" })
  db.users.deleteMany({ email: "test@example.com" })


================================================================================
BROWSER DEVTOOLS COMMANDS
================================================================================

Check Sentry initialization:
  Open DevTools Console
  Type: Sentry
  Should show Sentry object

Check localStorage:
  DevTools > Application > Local Storage
  Look for: token, user_id, etc.

Check cookies:
  DevTools > Application > Cookies
  Look for: accessToken, refreshToken

Monitor network requests:
  DevTools > Network
  Perform action
  Check request/response for integrations


================================================================================
DOCKER COMMANDS (Optional)
================================================================================

If using Docker for MongoDB:

Start MongoDB container:
  docker run -d -p 27017:27017 --name mongodb mongo

Stop MongoDB:
  docker stop mongodb

View MongoDB logs:
  docker logs mongodb

Connect to MongoDB in container:
  docker exec -it mongodb mongosh
