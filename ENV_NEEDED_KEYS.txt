STEP-BY-STEP FIX GUIDE:
================================================================================

STEP 1: Fix Calendar Keys
─────────────────────────

1. Go to Google Cloud Console: https://console.cloud.google.com/
2. Create new project (or use existing)
3. Enable Calendar API
4. Create Service Account:
   - Go to Service Accounts
   - Create new service account
   - Grant Editor role
5. Download JSON key:
   - Go to Keys tab
   - Create new key (JSON format)
   - Save the file
6. Extract these from the JSON file:
   - "project_id" → GOOGLE_CALENDAR_PROJECT_ID
   - "private_key" → GOOGLE_CALENDAR_PRIVATE_KEY (keep newlines as \n)
   - "client_email" → GOOGLE_CALENDAR_CLIENT_EMAIL

7. Get Calendar ID:
   - Go to Google Calendar: https://calendar.google.com/
   - Create new calendar for bookings
   - Get the calendar ID from settings

8. Update .env with:
   GOOGLE_CALENDAR_PROJECT_ID=your-project-id
   GOOGLE_CALENDAR_CLIENT_EMAIL=service-account@project-id.iam.gserviceaccount.com
   GOOGLE_CALENDAR_PRIVATE_KEY=-----BEGIN PRIVATE KEY-----\n...\n-----END PRIVATE KEY-----
   GOOGLE_CALENDAR_ID=calendar-id@gmail.com


STEP 2: Choose & Setup Video Provider
──────────────────────────────────────

OPTION A: Daily.co (Easiest)
1. Sign up: https://dashboard.daily.co/
2. Go to Developers section
3. Copy API key
4. Add to .env:
   NEXT_PUBLIC_VIDEO_PROVIDER=daily
   DAILY_API_KEY=your-api-key

OPTION B: Zoom
1. Go to: https://marketplace.zoom.us/
2. Create OAuth app
3. Get Client ID, Secret, Account ID
4. Add to .env:
   NEXT_PUBLIC_VIDEO_PROVIDER=zoom
   ZOOM_CLIENT_ID=your-client-id
   ZOOM_CLIENT_SECRET=your-secret
   ZOOM_ACCOUNT_ID=your-account-id

OPTION C: Agora (Already have some keys)
1. Already have: AGORA_APP_ID and AGORA_APP_SECRET
2. Just add to .env:
   NEXT_PUBLIC_VIDEO_PROVIDER=agora


STEP 3: Optional - Setup Analytics
────────────────────────────────────

For Google Analytics 4:
1. Go to: https://analytics.google.com/
2. Create GA4 property
3. Get Measurement ID (starts with G-)
4. Add to .env:
   NEXT_PUBLIC_GOOGLE_ANALYTICS_ID=G-XXXXXXXXXX
   GOOGLE_ANALYTICS_API_SECRET=your-secret


STEP 4: Cleanup .env
────────────────────

Remove/fix these lines:
- Remove: GOOGLE_CALENDAR_API_KEY=AIzaSyAi... (wrong key type)
- Remove duplicate: NEXT_PUBLIC_GOOGLE_MAPS_API_KEY= (empty one)

- Fix: GOOGLE_CALENDAR_CLIENT_EMAIL (should be service account, not Gmail)
