QUICK START: VERCEL DEPLOYMENT
===============================

TL;DR - Deploy in 5 minutes:

1. Files already configured:
   ✅ vercel.json - Build commands with --legacy-peer-deps
   ✅ .npmrc - Global npm config for legacy-peer-deps

2. Push to GitHub (main branch):
   git add .
   git commit -m "Ready for Vercel deployment"
   git push origin main

3. Connect to Vercel:
   - Visit vercel.com
   - Click "New Project"
   - Select your GitHub repository
   - Click "Import"

4. Add Environment Variables in Vercel Dashboard:
   Essential (required):
     DATABASE_URL = <your-mongodb-url>
     REDIS_URL = <your-redis-url>
     NEXT_PUBLIC_SENTRY_DSN = <your-sentry-dsn>
     JWT_SECRET = <generate-strong-random-string>
     NODE_ENV = production
   
   Google Calendar:
     GOOGLE_CALENDAR_PROJECT_ID = <your-id>
     GOOGLE_CALENDAR_CLIENT_EMAIL = <your-email>
     GOOGLE_CALENDAR_PRIVATE_KEY = <your-private-key>
     GOOGLE_CALENDAR_ID = <your-calendar-id>
     TIMEZONE = America/New_York
   
   Video Calls:
     NEXT_PUBLIC_VIDEO_PROVIDER = daily
     DAILY_API_KEY = <your-api-key>
   
   Analytics:
     NEXT_PUBLIC_GOOGLE_ANALYTICS_ID = <your-ga-id>
     GOOGLE_ANALYTICS_API_SECRET = <your-secret>
   
   Error Monitoring:
     NEXT_PUBLIC_APP_VERSION = 1.0.0

5. Click "Deploy"
   - Vercel will automatically build using vercel.json settings
   - Deployment takes 2-3 minutes
   - Get your production URL

Done! ✅

WHY --legacy-peer-deps?
======================

Next.js 16 is new, some packages haven't updated their peer dependency constraints yet:
  - @sentry/nextjs: expects Next.js 14 (works fine with 16)
  - next-cloudinary: expects Next.js 14 (works fine with 16)

The --legacy-peer-deps flag tells npm to proceed despite mismatches.
All packages work perfectly - the dependencies just haven't been updated yet.

TROUBLESHOOTING:
================

Build Failed?
  1. Check Build Logs in Vercel dashboard
  2. Look for npm error messages
  3. Verify all environment variables are set
  4. Clear cache: Settings → Advanced → Clear Build Cache
  5. Redeploy

Module Not Found?
  - Clear cache and redeploy
  - Ensure .npmrc exists in root
  - Check vercel.json has correct buildCommand

Deployment Stuck?
  - Wait 10 minutes (it's building)
  - If still stuck: click "Cancel" and "Redeploy"
  - Check Vercel status page

Database Connection Failed?
  - Verify DATABASE_URL environment variable
  - Check MongoDB is accessible (whitelist Vercel IPs)
  - Verify Redis connection (REDIS_URL)

CUSTOM DOMAIN:
==============

1. In Vercel dashboard → Project Settings → Domains
2. Click "Add Domain"
3. Enter your domain (stayfinderapp.com)
4. Update your domain registrar DNS:
   - Type: CNAME
   - Name: www (or subdomain)
   - Value: <provided by Vercel>
5. Wait 24-48 hours for DNS propagation
6. SSL certificate is automatic
