================================================================================
COMPLETE LIST OF ENVIRONMENT VARIABLES USED IN STAYERRA APPLICATION
================================================================================

This file lists all environment variables used across the entire application,
organized by category and purpose.

================================================================================
1. CORE APPLICATION
================================================================================

NODE_ENV=development
  Purpose: Application environment (development, production, staging)
  Used by: Everywhere - controls logging, error handling, caching
  Values: development, production, staging

NEXT_PUBLIC_APP_URL=http://localhost:3000
  Purpose: Base URL of the application
  Used by: Frontend components, API routes, video call integrations
  Visibility: Public (accessible from frontend)

================================================================================
ENVIRONMENT SETUP
================================================================================

DEVELOPMENT:
  Copy .env.example to .env.local and fill in your credentials.
  Most services are optional for local development.

PRODUCTION:
  Set all environment variables through your deployment platform
  (Vercel, Railway, AWS, etc.).
  
  Required for production:
  - NODE_ENV=production
  - JWT_SECRET (strong, random)
  - JWT_REFRESH_SECRET (strong, random)
  - MONGODB_URI (production database)
  - OPENAI_API_KEY (if using AI features)
  - STRIPE_SECRET_KEY or RAZORPAY credentials
  - SMTP credentials (for emails)
  - At least one analytics provider
  - At least one video provider (if using video calls)
  - Google Calendar (if using calendar bookings)
  - Sentry DSN (if using error monitoring)
