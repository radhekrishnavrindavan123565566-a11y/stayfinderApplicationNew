GOOGLE ADS - QUICK START (5 MINUTE SETUP)
=========================================

YOU HAVE:
✓ AdSense account created
✓ Publisher ID: ca-pub-xxxxxxxxxxxxxxxx

NOW DO THIS TO SEE ADS:


STEP 1: Create Ad Slots (2 minutes)
===================================

In AdSense Dashboard:
1. Click: Ads → By code
2. Click: CREATE NEW AD UNIT
3. Name: "Homepage Banner"
4. Type: Display ads
5. Size: Responsive
6. Click: CREATE
7. Copy the slot ID (number)

REPEAT 6 more times for each placement:
   Homepage Banner → NEXT_PUBLIC_ADSENSE_SLOT_HOME_HORIZONTAL
   Property Sidebar → NEXT_PUBLIC_ADSENSE_SLOT_PROPERTY_SIDEBAR
   Property Detail Top → NEXT_PUBLIC_ADSENSE_SLOT_PROPERTY_DETAIL_TOP
   Property Detail Bottom → NEXT_PUBLIC_ADSENSE_SLOT_PROPERTY_DETAIL_BOTTOM
   Dashboard Sidebar → NEXT_PUBLIC_ADSENSE_SLOT_DASHBOARD_SIDEBAR
   Search Results → NEXT_PUBLIC_ADSENSE_SLOT_SEARCH_RESULTS
   In-Article → NEXT_PUBLIC_ADSENSE_SLOT_IN_ARTICLE


STEP 2: Update .env (1 minute)
==============================

Open: .env (in your project)

Add/Update:
```
NEXT_PUBLIC_ADSENSE_PUBLISHER_ID=ca-pub-xxxxxxxxxxxxxxxx
NEXT_PUBLIC_ADSENSE_SLOT_HOME_HORIZONTAL=YOUR_SLOT_ID_1
NEXT_PUBLIC_ADSENSE_SLOT_PROPERTY_SIDEBAR=YOUR_SLOT_ID_2
NEXT_PUBLIC_ADSENSE_SLOT_PROPERTY_DETAIL_TOP=YOUR_SLOT_ID_3
NEXT_PUBLIC_ADSENSE_SLOT_PROPERTY_DETAIL_BOTTOM=YOUR_SLOT_ID_4
NEXT_PUBLIC_ADSENSE_SLOT_DASHBOARD_SIDEBAR=YOUR_SLOT_ID_5
NEXT_PUBLIC_ADSENSE_SLOT_SEARCH_RESULTS=YOUR_SLOT_ID_6
NEXT_PUBLIC_ADSENSE_SLOT_IN_ARTICLE=YOUR_SLOT_ID_7
```

Replace YOUR_SLOT_ID_X with actual numbers from AdSense


STEP 3: Add Ads to Pages (2 minutes)
===================================

Choose a page and add this code:

For HOMEPAGE (app/page.tsx):
```javascript
'use client';
import AdSenseAd from '@/components/ads/AdSenseAd';
import { AD_SLOTS } from '@/lib/adsense';

export default function HomePage() {
  return (
    <main>
      <h1>Welcome</h1>
      
      {/* Google Ad Here */}
      <AdSenseAd
        slotId={AD_SLOTS.homeHorizontal.slotId}
        slotName="homeHorizontal"
        format="auto"
        responsive={true}
      />
      
    </main>
  );
}
```

For DASHBOARD (app/dashboard/page.tsx):
```javascript
'use client';
import AdSenseAd from '@/components/ads/AdSenseAd';
import { AD_SLOTS } from '@/lib/adsense';

export default function DashboardPage() {
  return (
    <div className="flex gap-6">
      <main className="flex-1">Dashboard content</main>
      
      <aside className="w-80">
        {/* Google Ad Here */}
        <AdSenseAd
          slotId={AD_SLOTS.dashboardSidebar.slotId}
          slotName="dashboardSidebar"
          format="vertical"
          width={300}
          height={600}
        />
      </aside>
    </div>
  );
}
```

=================================

1. Save all files

3. Start dev server: npm run dev
4. Open: http://localhost:3000
5. Open DevTools: F12
6. Go to Console tab
7. Look for: [AdSense] Ad impression:

If you see that log → SUCCESS! ✓

COMMON ISSUES & FIXES
====================

"I don't see anything"
→ Check .env has NEXT_PUBLIC_ADSENSE_PUBLISHER_ID
→ Restart dev server: npm run dev
→ Check console for errors: F12 → Console

"Console shows undefined"
→ Slot ID empty in .env
→ .env variable not reloaded
→ Restart dev server: npm run dev

"No logs in console"
→ Component not added to page
→ Check you imported AdSenseAd correctly
→ Verify slot ID is valid

"Still no ads after 48 hours"
→ Check AdSense approval status
→ Look for approval email from Google
→ May need to fix policy issues
