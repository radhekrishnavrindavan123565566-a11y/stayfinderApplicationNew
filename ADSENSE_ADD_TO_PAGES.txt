HOW TO ADD GOOGLE ADS TO YOUR PAGES
====================================

Your ad components are created. Now you need to add them to your actual pages.
This file shows EXACTLY where to add ads.


CURRENTLY READY:
✓ AdSenseScript component (loads in ClientProviders)
✓ AdSenseAd component (created and available)
✓ .env configuration (set up for slots)

STILL NEEDED:
✗ Add AdSenseAd components to your pages


============================================
STEP 1: IDENTIFY WHERE YOU WANT ADS
============================================

Common locations:
1. Homepage (app/page.tsx)
2. Property listing page (app/properties/page.tsx)
3. Property detail page (app/properties/[id]/page.tsx)
4. Dashboard (app/dashboard/page.tsx)
5. Search page (where it exists)
6. Blog posts (if you have them)


============================================
STEP 2: ADD TO HOMEPAGE - app/page.tsx
============================================

Current code (without ads):
```
export default function HomePage() {
  return (
    <div>
      <HeroSection />
      <PropertyGrid />
    </div>
  );
}
```

Updated code (with ads):
```
import AdSenseAd from '@/components/ads/AdSenseAd';
import { AD_SLOTS } from '@/lib/adsense';

export default function HomePage() {
  return (
    <div>
      <HeroSection />
      
      {/* ADD AD HERE - between hero and grid */}
      <div className="my-8 px-4 max-w-7xl mx-auto">
        <AdSenseAd
          slotId={AD_SLOTS.homeHorizontal.slotId}
          slotName="homeHorizontal"
          format="auto"
          responsive={true}
        />
      </div>
      
      <PropertyGrid />
    </div>
  );
}
```

What changed:
- Added 2 import statements at top
- Added <AdSenseAd> component between sections
- Wrapped in div with padding and styling

STEP 3: ADD TO PROPERTY LISTING - app/properties/page.tsx
============================================

Current code:
```

    <div>
      <SearchFilters />

```

What changed:

- Main content in <main> element

============================================
STEP-BY-STEP EXAMPLE: Add to Homepage
============================================

1. Open file: app/page.tsx

2. Find the HomePage component

3. Add imports at top:
   ```
   import AdSenseAd from '@/components/ads/AdSenseAd';
   import { AD_SLOTS } from '@/lib/adsense';
   ```

4. Find where you want the ad (e.g., between hero and grid)

5. Add this block:
   ```
   <div className="my-8 px-4 max-w-7xl mx-auto">
     <AdSenseAd
       slotId={AD_SLOTS.homeHorizontal.slotId}
       slotName="homeHorizontal"
       format="auto"
       responsive={true}
     />
   </div>
   ```

6. Save file

7. Restart dev server:
   - Stop: Ctrl+C
   - Start: npm run dev

8. Visit http://localhost:3000

9. Check console (F12 → Console)
   - Should see: [AdSense] Ad impression: homeHorizontal (...)

10. Inspect ad element (right-click → Inspect)
    - Should see: <ins class="adsbygoogle" ...>


============================================
AFTER ADDING ADS
============================================

1. Run build to check for errors:
   npm run build

2. Fix any TypeScript errors if needed

3. Rebuild and test:
   npm run dev

4. Visit each page with ads

5. Verify console logs show ad impressions

6. Deploy to production when ready

7. Submit site for AdSense approval

8. Wait 24-48 hours for approval

9. Real ads will show after approval


============================================
OPTIONAL: DISABLE ADS FOR LOGGED-IN USERS
============================================

Some sites hide ads for paying users. Here's how:

```
import { useSession } from 'next-auth/react';

export default function PageWithAds() {
  const { data: session } = useSession();
  
  return (
    <>
      {/* Hide ads for premium/logged-in users */}
      {!session && (
        <div className="my-8">
          <AdSenseAd
            slotId={AD_SLOTS.homeHorizontal.slotId}
            slotName="homeHorizontal"
            format="auto"
            responsive={true}
          />
        </div>
      )}
      
      {/* Rest of page */}
    </>
  );
}
```
