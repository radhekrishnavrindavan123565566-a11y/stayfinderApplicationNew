HOW TO GET GOOGLE MAPS API KEY
==============================

Currently your .env has:
   NEXT_PUBLIC_GOOGLE_MAPS_API_KEY=your-google-maps-api-key-here

To get a real Google Maps API key:


STEP 1: Go to Google Cloud Console
===================================

1. Open: https://console.cloud.google.com/
2. Sign in with your Google account
3. If you don't have a project, create one:
   - Click "Select a Project" (top dropdown)
   - Click "New Project"
   - Enter name: "Stayerra Maps"
   - Click "Create"


STEP 2: Enable Google Maps API
===============================

1. In Google Cloud Console, go to: APIs & Services → Library
2. Search for: "Maps JavaScript API"
3. Click on it
4. Click "ENABLE" button
5. Wait for it to enable


STEP 3: Create API Key
======================

1. Go to: APIs & Services → Credentials
2. Click "Create Credentials" (blue button)
3. Select: "API Key"
4. Your API key will appear in a popup
5. Copy the key (looks like: AIzaSyD...)


STEP 4: Add to .env
===================

Edit .env file and change:

FROM:
   NEXT_PUBLIC_GOOGLE_MAPS_API_KEY=your-google-maps-api-key-here

TO:
   NEXT_PUBLIC_GOOGLE_MAPS_API_KEY=AIzaSyD1234567890...

Replace with your actual key from Step 3


STEP 5: Restrict Your API Key (Important for Security)
=======================================================

Back in Google Cloud Console:

1. Go to: APIs & Services → Credentials
2. Click your API key
3. Set restrictions:
   - Application restrictions: HTTP referrers
   - Add: localhost:3000 (for development)
   - Add: yourdomain.com (for production)
   - Add: *.vercel.app (for Vercel deployment)

4. Also set API restrictions:
   - Select only: Maps JavaScript API
   - Click "Save"


STEP 6: Restart Dev Server
===========================

1. Stop dev server: Ctrl+C
2. Start again: npm run dev
3. Open: http://localhost:3000/properties/[any-id]
4. Map should now load and show location

TROUBLESHOOTING
===============

Issue: "API key not valid" error
Solution:
   - Copy key exactly (no extra spaces)
   - Restart dev server after .env change
   - Make sure NEXT_PUBLIC_ prefix is included

Issue: Maps still shows loading spinner
Solution:
   - Clear browser cache: Ctrl+Shift+Del
   - Check if API key restrictions allow localhost:3000
   - Check browser console for errors: F12 → Console

Issue: "Maps API error: Invalid key"
Solution:
   - Go back to Google Cloud Console
   - Delete the key
   - Create a new one
   - Copy and paste into .env exactly
   - Restart dev server

Issue: "Too many requests" error
Solution:
   - You're being rate limited
   - This happens with free tier after many requests
   - Upgrade to paid plan or wait 24 hours


PRICING
=======

Google Maps API is FREE but with limits:

Free Tier:
   - $200/month free credit
   - ~25,000 map loads/month
   - Enough for small apps

Paid:
   - After free credit exhausted
   - ~$0.007 per map load
   - ~$7 per 1000 loads

For testing/development: FREE is fine
For production: Monitor usage, may need paid plan


SECURITY NOTE
=============

❌ DON'T:
   - Share API key publicly
   - Commit to GitHub without restrictions
   - Use in public repositories

✅ DO:
   - Set HTTP referrer restrictions
   - Use only for Maps JavaScript API
   - Keep to private repositories
   - Rotate keys periodically

Your key in .env is fine because:
   - .env is in .gitignore (not on GitHub)
   - Restrictions applied to the key itself
   - Only works with restricted origins
