TEST GOOGLE ADS - QUICK VERIFICATION
===================================

CURRENT STATUS: Your AdSense is set up but NO ADS ARE SHOWING YET

Reason: You haven't added the AdSenseAd component to any pages yet.


FASTEST WAY TO TEST (5 minutes)
===============================

STEP 1: Add Ad to Homepage
--------------------------

Edit: app/page.tsx

Find the export default function HomePage() { ... }

Add this after your main content starts:

```javascript
'use client';

import AdSenseAd from '@/components/ads/AdSenseAd';
import { AD_SLOTS } from '@/lib/adsense';
// ... other imports

export default function HomePage() {
  return (
    <main>
      {/* Your existing homepage content */}
      
      {/* ADD THIS SECTION */}
      <div className="my-8 px-4 max-w-7xl mx-auto">
        <AdSenseAd
          slotId={AD_SLOTS.homeHorizontal.slotId}
          slotName="homeHorizontal"
          format="auto"
          responsive={true}
        />
      </div>
      
      {/* Rest of content */}
    </main>
  );
}
```


STEP 2: Verify Your .env Has Ad Slots
--------------------------------------

Check: .env file

Should have these lines:

NEXT_PUBLIC_ADSENSE_PUBLISHER_ID=ca-pub-xxxxxxxxxxxxxxxx
NEXT_PUBLIC_ADSENSE_SLOT_HOME_HORIZONTAL=1234567890

If missing any slot IDs:
1. Go to AdSense → Ads → By code
2. Click "CREATE NEW AD UNIT"
3. Create a slot, copy the ID
4. Add to .env


STEP 3: Restart Dev Server
--------------------------

1. Stop current server: Ctrl+C
2. Start again: npm run dev
3. Open: http://localhost:3000


STEP 4: VERIFY ADS LOADING
--------------------------

On the homepage, you should see ONE of these:

OPTION A: Gray box appears
   Text: "[Ad Space - Enable Google AdSense]"
   Status: ✓ WORKING - This is normal!
   Why: Google hasn't approved yet (24-48 hours)

OPTION B: Colored ad box appears
   Shows Google ads
   Status: ✓ PERFECT - Ads are live!
   Why: Google already approved

OPTION C: Nothing visible
   Status: ⚠️ Debug needed
   Next steps: See DEBUGGING section below


STEP 5: CHECK DEVTOOLS CONSOLE
------------------------------

1. Open: http://localhost:3000
2. Press: F12
3. Click: Console tab
4. Look for blue text that says:
   "[AdSense] Ad impression: homeHorizontal (1234567890)"

If you see this → Ads component is working! ✓


STEP 6: CHECK NETWORK TAB
-------------------------

1. Still in DevTools
2. Go to: Network tab
3. Refresh page: F5
4. Search for: "pagead2.googlesyndication.com"
5. You should see a request with Status: 200

If you see it → AdSense script loaded! ✓


VERIFY IN INSPECTOR
-------------------

1. In DevTools
2. Go to: Inspector/Elements tab
3. Press: Ctrl+F
4. Search: "adsbygoogle"
5. Should find: <ins class="adsbygoogle">
6. Right-click it, select "Edit as HTML"
7. Should see:
   data-ad-client="ca-pub-xxxxx"
   data-ad-slot="1234567890"
   data-ad-format="auto"

If all present → Working correctly! ✓


DEBUGGING - ADS NOT SHOWING
===========================

PROBLEM: Nothing appears on page
----------------------------------

Check 1: Is .env loaded?
   In Console, type: process.env.NEXT_PUBLIC_ADSENSE_PUBLISHER_ID
   Should show: ca-pub-xxxxxxxxxxxxxxxx
   If undefined:
      - Restart dev server
      - Check .env file exists
      - Check NEXT_PUBLIC_ prefix

Check 2: Is component added to page?
   View page source (Ctrl+U)
   Search for: adsbygoogle
   If not found:
      - Verify import is correct
      - Check syntax of <AdSenseAd /> component
      - Make sure file is saved

Check 3: Check console errors
   F12 → Console
   Look for red error messages
   Common errors:
      - "Cannot find module" → Check import path
      - "slotId is empty" → Add slot ID to .env
      - "Module not found" → Restart dev server


PROBLEM: Still seeing gray placeholder after 48 hours
------------------------------------------------------

This means ads aren't approved yet. Check:

1. Go to AdSense dashboard
2. Look for approval email
3. Might be rejected for:
   - Policy violations
   - Insufficient content
   - Invalid traffic
   - Not matching AdSense policies

Fix:
   - Review AdSense policies
   - Check rejection reason in dashboard
   - Appeal or reapply


PROBLEM: See different thing on different pages
-------------------------------------------------

This is NORMAL!

Different pages can have:
   - Different ad sizes (300x600 vs 728x90)
   - Different ad formats (vertical vs horizontal)
   - Different content = different ads shown
   - Different slot IDs = different ad units
