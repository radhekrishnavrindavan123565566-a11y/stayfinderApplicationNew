HOW TO SEE GOOGLE ADS ON YOUR WEBSITE - COMPLETE GUIDE
=====================================================

YOU ARE HERE: Google AdSense Dashboard (shown in screenshot)
Now follow these exact steps to see ads on your website.


STEP 1: CREATE AD SLOTS IN ADSENSE DASHBOARD
=============================================

From your AdSense dashboard (where you are now):

1. Click "Ads" in left menu
2. Click "By code" (or "Ad units")
3. Click "CREATE NEW AD UNIT" button
4. Fill in the form:

   Name: Homepage Banner Ad
   Type: Display ads
   Size: Responsive (or 728x90)
   
5. Click CREATE
6. Copy the slot ID (it will show a number like: 1234567890)
7. REPEAT for each placement you want (7 total):

   □ Homepage Banner
   □ Property Sidebar
   □ Property Detail Top
   □ Property Detail Bottom
   □ Dashboard Sidebar
   □ Search Results
   □ In-Article


STEP 2: ADD SLOT IDS TO YOUR .env FILE
======================================

After creating slots, add them to: .env (in your project)

Example .env entries:

NEXT_PUBLIC_ADSENSE_PUBLISHER_ID=ca-pub-xxxxxxxxxxxxxxxx
NEXT_PUBLIC_ADSENSE_SLOT_HOME_HORIZONTAL=1234567890
NEXT_PUBLIC_ADSENSE_SLOT_PROPERTY_SIDEBAR=1234567891
NEXT_PUBLIC_ADSENSE_SLOT_PROPERTY_DETAIL_TOP=1234567892
NEXT_PUBLIC_ADSENSE_SLOT_PROPERTY_DETAIL_BOTTOM=1234567893
NEXT_PUBLIC_ADSENSE_SLOT_DASHBOARD_SIDEBAR=1234567894
NEXT_PUBLIC_ADSENSE_SLOT_SEARCH_RESULTS=1234567895
NEXT_PUBLIC_ADSENSE_SLOT_IN_ARTICLE=1234567896

⚠️ IMPORTANT: 
   - Restart your dev server after changing .env
   - Command: npm run dev


STEP 3: ADD ADSENSEADS COMPONENT TO YOUR PAGES
==============================================

Now add ads to the pages where you want them.

EXAMPLE 1: Add Ad to Homepage (app/page.tsx)
--------------------------------------------

'use client';

import AdSenseAd from '@/components/ads/AdSenseAd';
import { AD_SLOTS } from '@/lib/adsense';

export default function HomePage() {
  return (
    <main>
      {/* Your hero section */}
      <h1>Welcome to Stayerra</h1>
      
      {/* ADD THIS - Google Ad */}
      <div className="my-8">
        <AdSenseAd
          slotId={AD_SLOTS.homeHorizontal.slotId}
          slotName="homeHorizontal"
          format="auto"
          responsive={true}
        />
      </div>
      
      {/* Your content below */}
    </main>
  );
}

STEP 5: VERIFY ADS ARE LOADING
==============================

Open Developer Tools (F12) and check:

METHOD A: Check Console for Logs
---------------------------------
1. Press F12
2. Go to "Console" tab
3. Look for blue/green logs that say:
   "[AdSense] Ad impression: homeHorizontal (1234567890)"

If you see this → Ads component is working! ✓

METHOD B: Check Network for AdSense Script
------------------------------------------
1. Press F12
2. Go to "Network" tab
3. Refresh page (F5)
4. Search for: "pagead2.googlesyndication.com"
5. Should see it loaded with Status: 200

If you see it → AdSense script loaded! ✓

METHOD C: Inspect the Ad Element
--------------------------------
1. Press F12
2. Go to "Inspector" or "Elements" tab
3. Search for: "adsbygoogle"
4. Should find: <ins class="adsbygoogle">
5. Check attributes:
   - data-ad-client="ca-pub-xxxxx" ✓
   - data-ad-slot="1234567890" ✓

If all present → Element rendered correctly! ✓

METHOD D: Check What You See On Page
------------------------------------
You should see ONE of these:

OPTION 1: Gray placeholder box
   Text: "[Ad Space - Enable Google AdSense]"
   Meaning: Component working, just needs Google approval
   Status: ✓ NORMAL - Wait 24-48 hours

OPTION 2: Colored ad area with ads
   Shows actual Google ads
   Meaning: Google approved your site!
   Status: ✓ PERFECT - Ads live!

OPTION 3: Empty space, no placeholder
   Nothing visible
   Debug: Check .env has Publisher ID, restart server
   Status: ⚠️ Need to fix

TROUBLESHOOTING
===============

PROBLEM: I don't see any placeholder or ads
SOLUTION:
1. Check .env has NEXT_PUBLIC_ADSENSE_PUBLISHER_ID
2. Restart dev server: npm run dev
3. Clear browser cache: Ctrl+Shift+Del
4. Check DevTools console for errors: F12 → Console
5. Look for red error messages

PROBLEM: I see error in console
SOLUTION:
1. Read the error message carefully
2. Common errors:
   - "adsbygoogle is not defined" → Publisher ID wrong
   - "slotId is empty" → Slot ID not added to .env
   - "Cannot find module" → Component not imported correctly

PROBLEM: Placeholder shows but no real ads after 48 hours
SOLUTION:
1. Check AdSense dashboard for approval status
2. Look for approval email from Google
3. May have been rejected for policy violation
4. Check AdSense settings for requirements

PROBLEM: Different users see different ads
SOLUTION:
This is NORMAL and expected!
- Ads are contextual (based on user location, interests)
- Different browsers see different ads
- Mobile ads different from desktop
- This is working correctly!
