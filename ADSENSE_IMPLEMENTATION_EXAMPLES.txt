GOOGLE ADSENSE - QUICK IMPLEMENTATION EXAMPLES
==============================================

These are ready-to-use code examples for adding ads to your pages.

EXAMPLE 1: HOMEPAGE WITH BANNER AD
===================================

File: app/page.tsx

Add this import at the top:
import AdSenseAd from '@/components/ads/AdSenseAd';
import { AD_SLOTS } from '@/lib/adsense';

Add this JSX in your component between sections:

{/* After Hero Section, before Property Grid */}
<motion.div 
  initial={{ opacity: 0, y: 20 }}
  animate={{ opacity: 1, y: 0 }}
  className="my-12 px-4"
>
  <AdSenseAd
    slotId={AD_SLOTS.homeHorizontal.slotId}
    slotName="homeHorizontal"
    format="auto"
    responsive={true}
    className="rounded-lg overflow-hidden"
  />
</motion.div>

EXAMPLE 7: USING WITH CONDITIONS
================================

Only show ads for non-admin users:

import { useAuthStore } from '@/store/authStore';
import AdSenseAd from '@/components/ads/AdSenseAd';
import { AD_SLOTS } from '@/lib/adsense';

export default function HomePage() {
  const { user } = useAuthStore();
  const isAdmin = user?.role === 'admin';
  
  return (
    <div>
      <HeroSection />
      
      {/* Only show ads to non-admin users */}
      {!isAdmin && (
        <AdSenseAd
          slotId={AD_SLOTS.homeHorizontal.slotId}
          slotName="homeHorizontal"
          format="auto"
          responsive={true}
          className="my-8"
        />
      )}
      
      <PropertyGrid />
    </div>
  );
}

EXAMPLE 8: RESPONSIVE AD WRAPPER COMPONENT
==========================================

Create: components/ads/ResponsiveAdSection.tsx

'use client';

import AdSenseAd from './AdSenseAd';

interface ResponsiveAdSectionProps {
  slotId: string;
  slotName: string;
  title?: string;
  className?: string;
}

export default function ResponsiveAdSection({
  slotId,
  slotName,
  title,
  className = '',
}: ResponsiveAdSectionProps) {
  return (
    <div className={`my-8 p-4 bg-zinc-50 dark:bg-zinc-900 rounded-lg ${className}`}>
      {title && (
        <h3 className="text-sm font-semibold text-zinc-600 dark:text-zinc-400 mb-4">
          {title}
        </h3>
      )}
      <AdSenseAd
        slotId={slotId}
        slotName={slotName}
        format="auto"
        responsive={true}
      />
    </div>
  );
}

Then use like this:
<ResponsiveAdSection
  slotId={AD_SLOTS.homeHorizontal.slotId}
  slotName="homeHorizontal"
  title="Sponsored"
/>

COMMON ISSUES & SOLUTIONS
=========================

Issue: "Ad not rendering"
Check:
1. Publisher ID is correct in .env
2. Slot ID is correct
3. Site is approved in AdSense
4. Rebuild the application
5. Clear browser cache

Issue: "Placeholder showing instead of ads"
This is normal when:
- AdSense is disabled (NEXT_PUBLIC_ADSENSE_PUBLISHER_ID not set)
- Site not approved yet
- Slot ID is invalid
- Testing locally (ads may not show)

Issue: "Too many ads not loading"
Solution:
- AdSense has daily limits per page
- Remove duplicate ad slots
- Use only recommended placements
- Space out ads properly

PERFORMANCE OPTIMIZATION
========================

1. Lazy load ads:
import dynamic from 'next/dynamic';
const AdSenseAd = dynamic(() => import('@/components/ads/AdSenseAd'), {
  ssr: false,
});

2. Conditional rendering:
{!isMobile && <AdSenseAd {...props} />}

3. Use responsive ads:
responsive={true} // Adapts to container size

4. Monitor Core Web Vitals:
- Ensure ads don't slow down page
- Use AdSense dashboard metrics
- Test with Google PageSpeed Insights

VERIFICATION
============

Check if ads are working:
1. Open DevTools (F12)
2. Go to Console tab
3. Look for AdSense logs
4. Check Network tab for adsbygoogle.js load
5. Verify ins elements are present with data-ad-slot

In AdSense Dashboard:
1. Go to Ads → By code
2. Check "Ad review center" for blocked ads
3. View "Earnings" to see impressions/clicks
4. Check "Performance" tab for metrics
