VERCEL DEPLOYMENT GUIDE
=======================

This guide covers deploying the StayFinder application to Vercel.

AUTOMATIC SETUP COMPLETED:
==========================

The following files have been configured for Vercel:

1. ✅ vercel.json
   - installCommand: npm install --legacy-peer-deps
   - buildCommand: npm install --legacy-peer-deps && npm run build
   - crons: Configured for /api/cron/run-all at 9 AM daily

2. ✅ .npmrc
   - Configured with legacy-peer-deps=true
   - Applies globally to all npm operations

These configurations ensure Vercel uses the --legacy-peer-deps flag automatically.

DEPLOYMENT STEPS:
=================

1. CONNECT REPOSITORY TO VERCEL
   ---------------------------------
   
   a) Go to vercel.com and sign in
   b) Click "New Project"
   c) Select "Import Git Repository"
   d) Choose GitHub (or your git provider)
   e) Select: stayfinderApplicationNew (or your repo name)
   f) Click "Import"

2. CONFIGURE ENVIRONMENT VARIABLES
   ----------------------------------
   
   In Vercel Project Settings → Environment Variables, add:
   
   DATABASE & REDIS:
     DATABASE_URL = <your-mongodb-url>
     REDIS_URL = <your-redis-url>
   
   GOOGLE CALENDAR:
     GOOGLE_CALENDAR_PROJECT_ID = <your-project-id>
     GOOGLE_CALENDAR_CLIENT_EMAIL = <service-account-email>
     GOOGLE_CALENDAR_PRIVATE_KEY = <json-private-key>
     GOOGLE_CALENDAR_ID = <your-calendar-id>
     TIMEZONE = America/New_York
   
   VIDEO CALLS:
     NEXT_PUBLIC_VIDEO_PROVIDER = daily
     DAILY_API_KEY = <your-daily-api-key>
   
   ANALYTICS:
     NEXT_PUBLIC_GOOGLE_ANALYTICS_ID = <your-ga-id>
     GOOGLE_ANALYTICS_API_SECRET = <your-ga-secret>
   
   ERROR MONITORING:
     NEXT_PUBLIC_SENTRY_DSN = <your-sentry-dsn>
     NEXT_PUBLIC_APP_VERSION = 1.0.0
   
   PAYMENTS (if enabled):
     STRIPE_PUBLIC_KEY = <your-stripe-pk>
     STRIPE_SECRET_KEY = <your-stripe-sk>
     RAZORPAY_KEY_ID = <your-razorpay-key>
     RAZORPAY_KEY_SECRET = <your-razorpay-secret>
   
   AUTHENTICATION:
     JWT_SECRET = <generate-strong-secret>
     NODE_ENV = production
   
   EMAIL (optional):
     SMTP_HOST = <your-smtp-host>
     SMTP_PORT = 587
     SMTP_USER = <your-smtp-user>
     SMTP_PASS = <your-smtp-password>
   
   STORAGE:
     CLOUDINARY_CLOUD_NAME = <your-cloud-name>
     CLOUDINARY_API_KEY = <your-api-key>
     CLOUDINARY_API_SECRET = <your-api-secret>

3. VERIFY BUILD SETTINGS
   ----------------------
   
   In Vercel Project Settings → Build & Development Settings:
   
   Build Command: (should show: npm install --legacy-peer-deps && npm run build)
   Install Command: (should show: npm install --legacy-peer-deps)
   Output Directory: .next
   
   These are read from vercel.json automatically.

4. DEPLOY
   -------
   
   Option A - Automatic (Recommended):
     a) Push to GitHub main branch
     b) Vercel will auto-deploy on push
     c) Check deployment status in Vercel dashboard
     d) Vercel generates a unique URL for deployment
   
   Option B - Manual Deployment:
     a) Connect your GitHub repo
     b) Click "Deploy" in Vercel dashboard
     c) Wait for build to complete

5. VERIFY DEPLOYMENT
   -------------------
   
   a) Check Vercel dashboard for deployment status
   b) Click the deployment URL to visit your app
   c) Test each integration:
      - Calendar: POST /api/integrations/calendar/create
      - Video: POST /api/integrations/videocall/create
      - Analytics: POST /api/integrations/analytics/track
      - Errors: POST /api/integrations/errors/report
   d) Check logs for any errors

TROUBLESHOOTING:
================

Issue: "npm error code ERESOLVE"
Solution: 
  - Vercel is now using vercel.json buildCommand and installCommand
  - If you still get this error, try:
    1. Clear Vercel cache: Settings → Advanced → Clear Cache
    2. Redeploy: Click "Redeploy" on latest deployment
    3. Check .npmrc file exists in root

Issue: "Build failed"
Solution:
  1. Check Build Logs in Vercel dashboard
  2. Verify all environment variables are set
  3. Check DATABASE_URL and REDIS_URL are accessible
  4. Verify Google Calendar credentials are valid JSON
  5. Check Sentry DSN format is correct

Issue: "Module not found: @sentry/nextjs"
Solution:
  - Vercel should now use --legacy-peer-deps from vercel.json
  - If persists: Clear cache and redeploy

Issue: "Function too large"
Solution:
  - Vercel has serverless function size limits
  - Split large API routes into smaller files
  - Optimize dependencies

Issue: "Timeout during deployment"
Solution:
  - Clear build cache and redeploy
  - Check network connectivity to npm registry
  - Vercel dashboard → Settings → Advanced → Clear Cache

ENVIRONMENT-SPECIFIC VARIABLES:
===============================

You can set different values per environment:

1. In Vercel Settings → Environment Variables
2. Select Environment:
   - Production (main branch)
   - Preview (pull requests)
   - Development (local)

Example:
  DATABASE_URL (Production): mongodb+srv://prod...
  DATABASE_URL (Preview): mongodb+srv://preview...

CUSTOM DOMAINS:
===============

To add a custom domain:

1. Vercel Dashboard → Settings → Domains
2. Click "Add Domain"
3. Enter your domain (e.g., stayfinderapp.com)
4. Update your domain registrar DNS records:
   - Type: CNAME
   - Name: www (or subdomain)
   - Value: <vercel-provided-alias>
5. DNS updates take 24-48 hours to propagate
6. Vercel auto-configures SSL certificate

1. Database:
   - Use MongoDB Atlas with auto-scaling

   - Index frequently queried fields

2. Redis Cache:

3. CDN:
   - Vercel includes Vercel Edge Network (global CDN)

4. Serverless Functions:
