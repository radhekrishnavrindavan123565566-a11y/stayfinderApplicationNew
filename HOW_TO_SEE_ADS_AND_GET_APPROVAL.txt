HOW TO SEE GOOGLE ADS AND GET APPROVAL
======================================

CURRENT STATUS:
✅ ads.txt file created
✅ AdSense script added to layout
⏳ Approval status: Requires review
⏳ ads.txt status: Not found (checking)


STEP 1: Request Review
======================

1. In AdSense dashboard, click your site:
   "stayfinder-application-new-git-main-shiksha1.vercel.app"

2. Look for "Request review" or "Review" button
   (Blue button in the dashboard)

3. Click it to submit for review

4. Google will review your site (24-48 hours)


STEP 2: What Google Checks
==========================

Google reviewers will verify:

✅ ads.txt file accessible
   Check: https://yourdomain.com/ads.txt
   Should show your Publisher ID

✅ Public content visible
   - Homepage not behind login
   - About page exists
   - Contact page exists
   - Privacy policy exists

✅ Unique, original content
   - Real rental listings
   - User-generated content
   - Not duplicate content

✅ No policy violations
   - No adult content
   - No violence
   - No prohibited items
   - No misleading content


STEP 3: After Approval
======================

Once approved (usually 24-48 hours):

1. AdSense status changes to "Ready"
2. Real ads start appearing on your site
3. Earnings show in Reports section
4. Ads display in:
   - Homepage banner
   - Property listing sidebar
   - Property detail pages
   - Dashboard sidebar
   - Search results


HOW TO SEE ADS (Before Approval)
================================

Before approval, you'll see PLACEHOLDERS:

1. Visit: https://stayfinder-application-new-git-main-shiksha1.vercel.app/

2. Look for gray boxes with text:
   "[Ad Space - Enable Google AdSense]"

3. These are normal - they show real ads once approved

4. Check DevTools (F12) → Console for logs:
   [AdSense] Ad impression: homeHorizontal

5. If you see that log, ads are set up correctly!


HOW TO MONITOR APPROVAL
=======================

1. Go to AdSense → Sites
2. Check "Approval status" column
3. Possible statuses:
   - "Requires review" → Waiting for Google
   - "Getting ready" → In progress
   - "Ready" → Approved! Ads live

4. When approved:
   - ads.txt status changes to "Found"
   - Approval status changes to "Ready"
   - Real ads appear on site

TROUBLESHOOTING
===============

ads.txt shows "Not found":
   - Wait a few hours
   - File is at: public/ads.txt
   - URL must be: yourdomain.com/ads.txt
   - Refresh AdSense page (F5)

Approval taking longer than 48 hours:
   - Check for policy violations
   - Review Privacy Policy
   - Make sure Public content exists
   - Try requesting review again

Still shows "Requires review":
   - This is normal initially
   - Google is still reviewing
   - Can take 24-72 hours

No "Request review" button:
   - May already be submitted
   - Check "Status details"
   - Review in progress
