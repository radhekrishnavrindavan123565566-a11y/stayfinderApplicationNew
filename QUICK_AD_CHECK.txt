QUICK WAY TO CHECK GOOGLE ADS ON YOUR WEBSITE
=============================================

FASTEST METHOD (5 Minutes)
==========================

Step 1: Add Publisher ID to .env (if not already done)
   NEXT_PUBLIC_ADSENSE_PUBLISHER_ID=ca-pub-xxxxxxxxxxxxxxxx
   (Get this from: https://www.google.com/adsense/ → Settings → Account)

Step 2: Restart your dev server
   npm run dev

Step 3: Navigate to a page with an AdSenseAd component
   Examples where to add ads:
   - http://localhost:3000 (Homepage)
   - http://localhost:3000/dashboard (Dashboard)
   - http://localhost:3000/properties (Property listing)

Step 4: Open Browser DevTools
   Press F12 on your keyboard

Step 5: Check These 3 Things
   
   a) Go to "Console" tab
      Look for: [AdSense] Ad impression: ...
      This means component is working!

   b) Go to "Network" tab
      Look for requests to: pagead2.googlesyndication.com
      Status should be: 200
      This means AdSense script loaded!

   c) Go to "Elements" tab
      Search for: adsbygoogle
      Should find: <ins class="adsbygoogle">
      With attributes: data-ad-client and data-ad-slot
      This means ad element renders correctly!

Step 6: Result
   ✓ If you see all 3 above → Ads are set up correctly!
   ✓ You might see gray placeholder (this is normal initially)
   ✓ Real ads appear after Google approves (24-48 hours)


WHAT YOU'LL SEE
===============

GOOD SIGN - Placeholder Box Appears
----------------------------------
Gray box appears with text: "[Ad Space - Enable Google AdSense]"
OR
White/colored box appears with ad content
OR
Empty rectangle that looks like an ad space

This means:
✓ Everything is working!
✓ Just needs slot IDs or Google approval

GOOD SIGN - Console Logs
------------------------
Open DevTools → Console → Search "AdSense"

You should see:
   [AdSense] Ad impression: homeHorizontal (1234567890)

This means:
✓ Component rendered
✓ Slot ID loaded
✓ Script initializing


BAD SIGN - Nothing Appears
--------------------------
Nothing shows in the space where ad should be
Console shows errors

Debug:
1. Check .env has NEXT_PUBLIC_ADSENSE_PUBLISHER_ID
2. Restart dev server
3. Check if component is actually added to page
4. Look for errors in console


HOW TO ADD ADS TO PAGES
=======================

Quick Example for Homepage (app/page.tsx):

   'use client';

   import AdSenseAd from '@/components/ads/AdSenseAd';
   import { AD_SLOTS } from '@/lib/adsense';

   export default function HomePage() {
     return (
       <main>
         <h1>Welcome</h1>
         
         {/* Add this where you want the ad */}
         <AdSenseAd
           slotId={AD_SLOTS.homeHorizontal.slotId}
           slotName="homeHorizontal"
           format="auto"
           responsive={true}
         />
         
       </main>
     );
   }


Quick Example for Dashboard (app/dashboard/page.tsx):

   'use client';

   import AdSenseAd from '@/components/ads/AdSenseAd';
   import { AD_SLOTS } from '@/lib/adsense';

   export default function DashboardPage() {
     return (
       <div className="flex gap-6">
         <main className="flex-1">
           {/* Dashboard content */}
         </main>
         
         <aside className="w-80">
           {/* Sidebar Ad */}
           <AdSenseAd
             slotId={AD_SLOTS.dashboardSidebar.slotId}
             slotName="dashboardSidebar"
             format="vertical"
             width={300}
             height={600}
           />
         </aside>
       </div>
     );
   }


TESTING AFTER DEPLOY
====================

Once you deploy to production:

1. Visit your website: https://yourdomain.com
2. Open DevTools (F12)
3. Go to Console tab
4. Look for: [AdSense] Ad impression: logs
5. If you see them, ads are working on production!
6. Wait 24-48 hours for Google approval
7. Real ads will appear after approval


.ENV VARIABLES NEEDED
====================

At minimum, you need:

NEXT_PUBLIC_ADSENSE_PUBLISHER_ID=ca-pub-xxxxxxxxxxxxxxxx

Optional (for specific ad slots):
NEXT_PUBLIC_ADSENSE_SLOT_HOME_HORIZONTAL=1234567890
NEXT_PUBLIC_ADSENSE_SLOT_DASHBOARD_SIDEBAR=1234567894
NEXT_PUBLIC_ADSENSE_SLOT_PROPERTY_SIDEBAR=1234567891
... (others as needed)

Without .env variables, you'll see placeholder boxes only.


AFTER APPROVAL - REAL ADS APPEAR
================================

Once Google approves your website (24-48 hours):

1. You'll see real Google ads instead of placeholders
2. Ads are contextual (related to content)
3. Earnings start showing in AdSense dashboard
4. Different ads on different pages
5. Ads refresh with each page load
6. Can appear as banners, squares, rectangles


MONITOR EARNINGS
================

View your earnings:
1. Go to: https://www.google.com/adsense/
2. Click: Reports
3. See: Earnings, impressions, clicks, RPM
4. By default shows last 30 days

COMMON QUESTIONS
================

Q: I see gray box, why no ads?
A: Google hasn't approved your website yet (24-48 hours)
   This is normal! Component is working correctly.

Q: Why do I see different things on different pages?
A: Different pages can have different ad slots.
   Check which AdSenseAd components are added where.

Q: Can I test ads before approval?
A: Yes! Placeholder appears during testing.
   Real ads only after Google approval.

Q: Why no Console logs?
A: Check .env file has NEXT_PUBLIC_ADSENSE_PUBLISHER_ID
   Restart dev server after changing .env

Q: How much money will I make?
A: Depends on:
   - Traffic volume
   - Content quality
   - Geographic location
   - User engagement
   Typical: $2-5 per 1000 impressions

Q: Can I change ad placements?
A: Yes! Just add/remove AdSenseAd components
   Ads will appear/disappear from those locations
